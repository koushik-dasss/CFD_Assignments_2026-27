# Q2 - Run Nginx detached and map host port 8080 to container port 80

sudo docker pull nginx
Output=>
Using default tag: latest
latest: Pulling from library/nginx
...
Status: Downloaded newer image for nginx:latest
(Note: Docker may report that the image is already up to date.)

sudo docker run -d --name mynginx -p 8080:80 nginx
Output=>
<container-id>

sudo docker ps
Output=>
CONTAINER ID   IMAGE   COMMAND                  STATUS   PORTS                  NAMES
<id>           nginx   "/docker-entrypoint.…"   Up ...   0.0.0.0:8080->80/tcp   mynginx

sudo docker port mynginx
Output=>
80/tcp -> 0.0.0.0:8080
80/tcp -> [::]:8080

curl http://localhost:8080
Output=>
<!DOCTYPE html>
<html>
<head>
<title>Welcome to nginx!</title>
...
(Note: the complete HTML response is longer.)

Browser:
http://localhost:8080

sudo docker logs mynginx
Output=>
Nginx startup messages and any requests logged by the container.

Notes:
- -d runs the container in the background.
- -p 8080:80 maps host port 8080 to container port 80.
- If mynginx already exists, remove or rename that container before rerunning.
